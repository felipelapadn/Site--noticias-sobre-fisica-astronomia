# Site--noticias-sobre-fisica-astronomia

O site aqui apresentado foi feito como uma proposta de projeto final para a disciplina de Linguagem de Estruturação e Apresentação de Conteúdos. A ideia do site é divulgar notícias do campo da física e da astronomia, mas não foi aplicado nenhuma colota de API ou links trabalhando dentro do site, já que a proposta da disciplina era trabalhar com o HTML, CSS e JavaScript.

## Página contato

A página contato possui um formulário simples. Caso o formulário não esteja preenchido corretamente, será incluída uma ```div``` na página com a mensagem "Algo está faltando...", caso contrário mostrará "Senhor X, a sua mensagem foi enviada aos comandantes".

## Página sobre

A página "sobre" explica brevemente a minha trajetória até o momento em que fiz o site (29/06/2022). A logo do site foi feita no software Inkscape e é totalmente autoral, a ideia que eu tive ao fazer a logo do site é a de um foguete em uma órbita, na órbita temos a Terra com a Lua e Saturno. A ideia em si não é muito astronômica, peço desculpas. A página "sobre" possui um pequeno Easter Egg, ao clicar em um ponto da tela, ela troca de cor para branca.
